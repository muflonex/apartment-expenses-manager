# Glossary

## Community
Expenses associated with the apartment owners' community.

Spanish: comunidad.

## Dashboard
The main application view containing aggregated information about
expenses.

Spanish: panel / resumen.

## Expense
A financial amount associated with the apartment.

Spanish: gasto.

## Expense category
The classification assigned to an expense.

Spanish: categoría de gasto.

## Expense list
The view containing individual recorded expenses.

Spanish: lista de gastos.

## Frequency
The recurrence interval of an expense.

Supported values:

- monthly
- quarterly
- yearly

Spanish: frecuencia.

## Insurance
Insurance associated with the apartment.

Spanish: seguro.

## Loan
A loan associated with the apartment, such as a renovation loan.

Spanish: préstamo.

## Maintenance
Expenses related to maintenance, repairs or improvements.

Spanish: mantenimiento.

## Monthly summary
A summary of expenses grouped by month.

Spanish: resumen mensual.

## Mortgage
Regular payments associated with the apartment mortgage.

Spanish: hipoteca.

## MVP
Minimum Viable Product.

The smallest version of the application that provides the core
expense-management functionality.

Spanish: producto mínimo viable.

## One-off expense
An expense that does not repeat.

Spanish: gasto puntual.

## Recurring expense
An expense that repeats according to a defined frequency.

Spanish: gasto recurrente.

## Special assessment
An exceptional payment requested by the apartment owners' community.

Spanish: derrama.

## Subscription
A recurring service subscription associated with the apartment.

Spanish: suscripción.

## Taxes
Taxes associated with the apartment.

Examples include IBI.

Spanish: impuestos.

## Utilities
Household utility expenses such as electricity, gas and water.

Spanish: suministros.
